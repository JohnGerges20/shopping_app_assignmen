# 📘 Flutter Course – Section 5

This repository contains the Flutter projects for **Section 5** of the Flutter course.

Each folder is a separate Flutter project. Open the required project folder in your IDE to run and explore it.

## 📂 Projects

| Project | Topics |
|---|---|
| 🛒 [**full_shopping_app**](full_shopping_app/) | Signup & Login, Navigation with `go_router` (`go`, `push`, `pop`), Route Guards, Forms & Validation, `TextEditingController`, `const`, `super.key`, and Private State Classes |
| 🔑 [**keys**](keys/) | Widget and State relationship, and the importance of Keys (`ValueKey`, `ObjectKey`, `UniqueKey`) |

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/JohnGerges20/shopping_app_assignmen.git
```

### 2. Open a project

For the Shopping App:

```bash
cd shopping_app_assignmen/full_shopping_app
```

### 3. Install dependencies

```bash
flutter pub get
```

### 4. Run the application

```bash
flutter run
```

> **Note:** Open the individual project folder (e.g. `full_shopping_app`) in your IDE, not the repository root. Each project has its own `pubspec.yaml`.
